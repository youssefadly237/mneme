# Mneme

A local spaced repetition flashcard app, like Anki? yes, but without the
complexity, you can do more with Anki, but Mneme is easier

## stack

- rust
- egui
- ratex
- rusqlite
- comark
- fsrs

## dev stage

Mneme is hosted on my gitea instance rn, under heavy devlepment

It is still far from complete, once it reaches a level I feel is
worth publishing, I'll release it on GitHub
